# Clear & Conquer — 225-image library

Extract the ZIP completely, then open image-library.html in a browser.
No installation or account is needed to browse the catalog.

- public/images/beginner: 100 SVG images.
- public/images/moderate: 75 SVG images.
- public/images/expert: 50 SVG images.

Every image has a 600×400 viewBox. These are vector icons, diagrams and code illustrations, not photographs.
The catalog includes answers and facts for teacher review. It should not be displayed to players before a guessing session.
image-catalog.json lists all clue IDs, difficulty modes, paths, aliases, facts and further-reading links.
Keep ASSET-LICENSES.md with redistributed images.

To install these in the accompanying updated game, preserve the public/images subfolders.
The older 18-clue game also needs the updated source catalog and per-mode engine from the complete game ZIP.
